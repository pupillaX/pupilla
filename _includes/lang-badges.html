{%- comment -%} Renders the language badges for an article/essay item, e.g. EN IT. Usage: {% include lang-badges.html item=item %} Shows the languages the full text is available in (see text-langs.html), falling back to abstracts. Each badge is a flex child of .archive-meta, so spacing comes from its gap. {%- endcomment -%} {%- include text-langs.html item=include.item -%} {%- assign _langs = text_langs -%} {%- unless _langs -%}{%- assign _langs = include.item.abstracts | map: 'language' -%}{%- endunless -%} {%- if _langs -%}{%- for l in _langs -%}{% include lang-badge.html language=l %}{%- endfor -%}{%- endif -%}
